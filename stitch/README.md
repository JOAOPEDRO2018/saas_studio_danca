## Outros arquivos

- [DESIGN.md](../DESIGN.md), na raiz do repositório: o design system do projeto ("Studio Elegance SaaS"), com cores, tipografia (Plus Jakarta Sans), espaçamentos, sombras e regras dos componentes. A cor primária é `#b8387c`.
- [referencias/](referencias/): o logo da IsaDance que foi enviado ao Stitch, com uma versão para fundo claro e outra para fundo escuro. São cópias reduzidas, com 512 px de altura. Para usar no produto, prefira o arquivo original do logo.

## Observações

- Os HTML usam Tailwind por CDN (`cdn.tailwindcss.com`), as fontes do Google e imagens hospedadas no Google. Por isso só renderizam direito com internet.
- A foto de perfil no topo das telas 02 a 07 é uma imagem privada da conta Google que criou o projeto. Ela só aparece para quem está logado nessa conta.
- A tela 08 é quase idêntica à tela de Login (01). Parece ser uma versão anterior dela.
- No quadro do Stitch, várias telas ainda aparecem com o rótulo "Generating Screen...". É só o rótulo, porque as telas estão completas. Se quiser, renomeie as telas no próprio Stitch.
- A imagem da tela 08 foi gerada localmente com o Chrome em modo headless. As outras imagens vieram da exportação do Stitch.
